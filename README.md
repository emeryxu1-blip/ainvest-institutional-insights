# AInvest · Institution AI insights

[Open the snapshot-based widget](https://emeryxu1-blip.github.io/ainvest-institutional-insights/?prototype=snapshot)

**Where Institutions Move Next** presents Buy Signals, Sell Signals and Fund Forecasts from supplied model targets and sourced asset evidence. Dollar values are calculated changes in target allocation value, not observed trades or cash flows.

This prototype contains only the initial widget and its three tabs. Fund Forecasts emphasizes institutions, groups fund codes beneath each name and leads with expected dollar target changes. View all remains visible as an inactive prototype control. There are no internal secondary screens, detail views or search. Source calculations and dated evidence are retained in the maintained project.

[Open the future-plan prototype](https://emeryxu1-blip.github.io/ainvest-institutional-insights/)

The original experience presents independent AI institution replicas, illustrative expected stock moves, dollar positions and simulated performance. Its existing destinations remain available.

This repository contains the verified static presentation build. Original source snapshots and research archives are retained in the maintained local project and are not included here. The named institutions do not endorse or manage these independent prototypes.
